# 주제 뱅크 (로테이션용)

매 실행마다 아래 카테고리를 순환하며, `posted/` 폴더에 이미 다룬 제목이 있으면 건너뛰고 다른 소재를 선택합니다.
하루 2개 발행 기준: 카테고리 A/B/C를 요일별로 섞어서 배정합니다.

## A. 대출상품 안내
- 개인신용대출이란 무엇인가 (개념/대상/절차)
- 담보대출과 신용대출의 차이
- 대환대출(대출 갈아타기)이 필요한 시점
- 소액생계비대출 안내
- 자영업자·프리랜서 대출 시 준비서류
- 만 19세~34세 청년 대상 대출 지원제도 비교
- 대출 한도는 어떻게 결정되나 (소득, 신용점수, DSR)
- 대부업체 이용 시 반드시 확인할 5가지 (등록번호 조회 방법 포함)
- 대출 상담 전 미리 준비하면 좋은 서류 체크리스트
- 급전이 필요할 때 고려할 수 있는 선택지 비교 (제도권 중심)

## B. 금융/신용 상식
- 신용점수(신용평점)는 어떻게 계산되나
- 신용점수를 올리는 습관 5가지
- 연체가 신용점수에 미치는 영향과 회복 기간
- 법정 최고금리란 무엇인가
- DSR(총부채원리금상환비율) 쉽게 이해하기
- 금리 인하 요구권이란 무엇이고 어떻게 신청하나
- 불법 사금융 구별법과 신고 방법
- 서민금융진흥원 등 정책 서민금융상품 소개
- 신용카드 현금서비스와 대출의 차이
- 대출 갈아타기(대환) 전 확인해야 할 것들

## C. 고객 후기 / FAQ
- 상담부터 실행까지 걸리는 시간 FAQ
- 자주 묻는 질문: 신용점수가 낮아도 상담 가능한가요
- 자주 묻는 질문: 중도상환수수료가 있나요
- 자주 묻는 질문: 서류는 온라인으로도 제출 가능한가요
- 상담 시 자주 나오는 오해와 진실
- 이용 고객 후기 (가명/각색, 특정인 식별 불가 형태로만 작성 — 실제 후기 미확보 시 생성하지 말고 스킵)

## 요일별 카테고리 배정 (하루 2개 기준)
| 요일 | 1번째 | 2번째 |
|------|-------|-------|
| 월 | A | B |
| 화 | B | C |
| 수 | A | B |
| 목 | B | A |
| 금 | A | C |
| 토 | B | A |
| 일 | C | A |

- C(후기/FAQ)는 소재 수가 적으므로 주 2회로 제한하고 나머지는 A/B로 채웁니다.
- 위 배정은 기본값이며, 특정 카테고리의 미사용 소재가 소진되면 다른 카테고리로 자동 대체합니다.

## 소재 소진 시 처리
- 각 카테고리 소재는 10개 내외로, 하루 2개씩 발행 시 1~2주 내 소진될 수 있습니다.
- `posted/`에 이미 있는 제목과 **완전히 동일한 제목**은 건너뛰고, 유사 주제는 각도를 바꿔(예: 대상 세분화, 최신 이슈 반영, 계절/시기 이벤트 연계) 재사용합니다.
- 카테고리 A/B 소재가 모두 소진되면 아래 예비 소재 뱅크에서 보충합니다.

### 예비 소재 뱅크 (A/B 소진 시)
- 금융감독원 등록 대부업체 조회 방법 (실전 가이드)
- 대출 상담 시 자주 하는 실수 5가지
- 신용점수 등급별 대출 가능성 이해하기
- 대출 계약서 확인 시 꼭 봐야 할 조항
- 중도상환수수료·연체이자 계산 개념 정리
- 대부업과 저축은행·캐피탈의 차이
- 채무조정제도(개인워크아웃 등) 간단 소개

## 사용 규칙
- "고객 후기"는 실제 후기 원문이 없으면 절대 지어내지 않습니다. 대신 FAQ나 상식 콘텐츠로 대체합니다.
- 특정 대출 실행을 직접적으로 유도/보장하는 표현("무조건 승인", "누구나 가능") 금지.
- 이자율, 한도 등 구체적 수치는 함부로 확정하지 말고 "상담을 통해 확인" 톤으로 작성.
- 제목 매칭은 정확히 동일한 제목뿐 아니라 핵심 키워드(예: "대환대출", "DSR")가 최근 7일 내 이미 사용됐는지도 함께 확인해 과도한 키워드 중복을 피합니다.
