# 작성 가이드 (네이버 블로그용)

## 톤 & 형식
- 존댓말, 친절하고 신뢰감 있는 톤. 과장/자극적 표현 금지.
- 글자 수: 1,200~1,800자 내외 (공백 포함), 네이버 블로그 검색 노출에 무난한 길이.
- 구조: 도입(공감/질문) → 소제목 3~4개로 본문 → 요약 → 고지 블록.
- 소제목은 `## `로 표시 (네이버 에디터에 옮길 때 굵게 처리 기준).
- 문단은 2~4줄 단위로 짧게 끊기 (모바일 가독성).

## SEO
- 제목 후보 3개 제시 (핵심 키워드를 앞쪽에 배치).
- 본문에 사용할 태그 10개 내외 제안 (예: #신용대출 #제주대부업 #대환대출 등).
- 지역 키워드(제주, 제주시 등) 자연스럽게 1~2회 포함.

## 준수 사항 (매우 중요)
- 특정 금리·한도를 확정적으로 약속하는 표현 금지 ("무조건", "100% 승인", "당일 입금 보장" 등).
- "신용점수 조회는 무료이며 조회 자체는 신용점수에 영향을 주지 않습니다" 같은 정확한 정보만 사용, 불확실하면 "확인이 필요합니다"로 표현.
- 실존하지 않는 고객 후기·통계·수치를 지어내지 않는다.
- 매 글 말미에 `config/company.md`의 표준 고지 문구를 그대로 삽입한다 (금리 placeholder 포함, 발행 전 사람이 채워야 함을 draft 상단에 메모로 남긴다).

## 초안 파일 형식
파일명: `drafts/YYYY-MM-DD-순번-slug.md`

파일 상단에 아래 메타 블록 포함:
```
---
category: A|B|C  (대출상품 안내 / 금융신용상식 / 고객후기FAQ)
status: draft-review-needed
generated_at: <생성 일시>
---
```

이어서 제목 후보, 태그 후보, 본문, 고지 블록 순으로 작성.
