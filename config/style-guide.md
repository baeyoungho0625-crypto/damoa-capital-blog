# 작성 가이드 (네이버 블로그용)

## 톤 & 형식
- 존댓말, 친절하고 신뢰감 있는 톤. 과장/자극적 표현 금지.
- 글자 수: 1,200~1,800자 내외 (공백 포함), 네이버 블로그 검색 노출에 무난한 길이.
- 구조: 도입(공감/질문) → 소제목 3~4개로 본문 → 요약 → 고지 블록.
- 소제목은 `## `로 표시 (네이버 에디터에 옮길 때 굵게 처리 기준).
- 문단은 2~4줄 단위로 짧게 끊기 (모바일 가독성).

## SEO
- 제목 후보 3개 제시 (핵심 키워드를 앞쪽에 배치).
- 본문에 사용할 태그 10개 내외 제안 (예: #신용대출 #제주대부업 #대환대출 등).
- 지역 키워드는 **제주시와 서귀포시를 함께** 자연스럽게 포함 (제주시만 쓰지 않기 — 서귀포 지역 고객도 대상).
- 실제 홈페이지(https://damoacapital.co.kr/)에서 쓰는 상품명/키워드를 태그에 반영: 제주당일대출, 제주소액대출, 제주급전, 제주일수, 제주개인대출, 제주신용대출, 제주무직자대출, 제주사업자대출, 제주대출, 서귀포대출 등. 매 글마다 전부 넣기보다 글 주제와 맞는 3~5개만 골라 태그에 섞어 쓴다.
- 홈페이지 대출 한도(100만원~3000만원)나 상품명을 본문에 인용할 때도 확정적 약속 톤이 아니라 "취급 가능한 범위" 톤으로 서술한다.

## 준수 사항 (매우 중요)
- 특정 금리·한도를 확정적으로 약속하는 표현 금지 ("무조건", "100% 승인", "당일 입금 보장" 등).
- "신용점수 조회는 무료이며 조회 자체는 신용점수에 영향을 주지 않습니다" 같은 정확한 정보만 사용, 불확실하면 "확인이 필요합니다"로 표현.
- 실존하지 않는 고객 후기·통계·수치를 지어내지 않는다.
- 매 글 말미에 `config/company.md`의 표준 고지 문구를 그대로 삽입한다 (연 20% 고정 금리 포함, 다른 수치로 바꾸지 않는다).
- 고지 문구 마지막 줄의 홈페이지 URL(`https://damoacapital.co.kr/`)은 단독 줄로 두어 네이버 에디터에서 자동 링크 미리보기 카드가 생성되도록 한다 (다른 텍스트와 같은 줄에 섞지 않는다).

## 초안 파일 형식
파일명: `drafts/YYYY-MM-DD-순번-slug.md`

파일 상단에 아래 메타 블록 포함:
```
---
category: A|B|C  (대출상품 안내 / 금융신용상식 / 고객후기FAQ)
status: draft-review-needed
generated_at: <생성 일시>
---
```

이어서 제목 후보, 태그 후보, 본문, 고지 블록 순으로 작성.

## 이미지 규칙
- 초안 1개당 Unsplash 사진 1장을 `drafts/images/YYYY-MM-DD-순번.jpg`로 저장 (초안 파일명과 날짜/순번 일치).
- 이미지는 대출/금융을 은유적으로 표현하는 안전한 소재(사무실, 계산기, 서류, 상담 장면, 도시 풍경 등)만 사용하고, 특정 인물이 얼굴을 드러내며 "고객"으로 오인될 수 있는 사진은 피합니다.
- 초안 본문 하단(고지 블록 앞)에 사진 출처 캡션을 남깁니다: `사진: Unsplash (@작가명)` 형식.
- 사진과 무관하게 확정적 문구("승인 100%" 등 연상시키는 이미지 텍스트 오버레이)는 사용하지 않습니다.

## 금지 표현 체크리스트 (게시 전 필수 확인)
- "무조건 승인", "누구나 가능", "100% 승인", "당일 즉시 입금 보장" 등 확정/보장형 표현
- 특정 금리·한도를 사실처럼 단정하는 표현 (연 20% 고정 금리 외 다른 수치를 임의로 제시하는 경우 포함)
- 실존하지 않는 고객 후기, 통계, 설문 수치
- 경쟁 대부업체·금융기관을 비방하거나 직접 비교하는 표현
- 채무자를 심리적으로 압박하거나 긴급성을 과도하게 조장하는 표현("지금 아니면 늦습니다" 류)
- 고지 블록 누락 또는 수치 임의 변경 (특히 "연 20%" 금리 고정 문구)
