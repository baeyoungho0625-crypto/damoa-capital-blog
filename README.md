# damoa-capital-blog

다모아캐피탈대부 네이버 블로그 + 인스타그램용 콘텐츠 자동 생성 저장소.

매일 08:00(KST)에 클라우드 자동화 에이전트가 실행되어 `drafts/`에 블로그 초안 1~2개, `instagram/drafts/`에 짝을 이루는 인스타 캡션을 함께 생성·커밋합니다.
네이버 블로그와 인스타그램 모두 공식 오픈 API로 자동 발행이 어려워 — 초안까지만 자동화하고, 검토 후 직접 게시하세요.

## 폴더 구조
- `config/company.md` — 필수 고지사항(등록번호 등) 및 표준 문구 (금리 연 20% 고정, 홈페이지 링크 포함)
- `config/topics.md` — 순환 발행할 주제 뱅크 및 작성 규칙
- `config/style-guide.md` — 블로그 톤, 형식, SEO, 준수사항 가이드
- `config/instagram-style-guide.md` — 인스타그램 캡션 형식/해시태그/고지문구 가이드
- `drafts/` — 자동 생성된 블로그 초안 (발행 전 검토 필요)
- `drafts/images/` — 각 초안에 딸린 Unsplash 사진 (초안과 같은 날짜/번호로 매칭, 인스타에도 재사용)
- `posted/` — 발행 완료된 블로그 글 (주제 중복 방지용 기록)
- `instagram/drafts/` — 자동 생성된 인스타 캡션 (같은 날짜/번호의 블로그 글과 짝)
- `instagram/posted/` — 게시 완료된 인스타 캡션 기록

## 발행 전 체크리스트 (블로그)
1. 과장/확정 표현이 없는지 확인
2. 네이버 블로그 에디터에 본문 텍스트 + `drafts/images/`의 해당 사진을 함께 붙여넣기 (초안 안내에 사진 출처 캡션 포함)
3. 발행
4. 발행 완료 후 해당 .md/.jpg 파일을 `drafts/`에서 `posted/`로 이동 (다음 자동 생성 시 중복 방지)

## 게시 전 체크리스트 (인스타그램)
1. `instagram/drafts/`에서 짝이 되는 캡션 확인, 축약 고지문구 빠지지 않았는지 확인
2. 인스타그램 앱에서 같은 날짜/번호의 사진(`drafts/images/`)과 캡션으로 게시 (프로필 링크에 다모아캐피탈.com 등록 필요)
3. 게시 완료 후 `instagram/drafts/`에서 `instagram/posted/`로 이동
