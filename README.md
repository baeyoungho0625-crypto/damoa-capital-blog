# damoa-capital-blog

다모아캐피탈대부 네이버 블로그용 콘텐츠 자동 생성 저장소.

매일 08:00(KST)에 클라우드 자동화 에이전트가 실행되어 `drafts/` 폴더에 초안 1~2개를 생성·커밋합니다.
네이버 블로그는 공식 오픈 API가 없어 자동 발행은 하지 않습니다 — 초안을 검토/수정한 뒤 직접 블로그에 붙여넣어 발행하세요.

## 폴더 구조
- `config/company.md` — 필수 고지사항(등록번호 등) 및 표준 문구
- `config/topics.md` — 순환 발행할 주제 뱅크 및 작성 규칙
- `config/style-guide.md` — 톤, 형식, SEO, 준수사항 가이드
- `drafts/` — 자동 생성된 초안 (발행 전 검토 필요)
- `posted/` — 실제 발행 완료된 글 (제목만 이동해서 주제 중복 방지용으로 기록)

## 발행 전 체크리스트
1. `config/company.md`의 금리 placeholder를 실제 값으로 채웠는지 확인
2. 과장/확정 표현이 없는지 확인
3. 네이버 블로그 에디터에 옮겨 발행
4. 발행 완료 후 해당 파일을 `drafts/`에서 `posted/`로 이동 (다음 자동 생성 시 중복 방지)
